# BlackHoleGram 12.10.6-bhg.67

The Black Hole launcher icon now uses cinematic raster artwork prepared from the user's supplied upper black-hole reference: a bright white ring, an orange accretion disk and a black background. Screenshot controls and text are excluded, and equal foreground padding keeps the light ring centered in launcher masks. Adaptive and legacy icons and the settings selector use the same artwork; the themed monochrome fallback and all existing icon choices remain available. The alias and current selection are unchanged. Only this raster icon's selector foreground is clipped to the existing circular preview path, preventing opaque corners from extending beyond the circular background without changing older icons.

The artwork was prepared with the built-in image tool, then deterministically resized to a 512 x 512 opaque PNG for Android. This is an image-based rendition of the reference, not a claim of pixel-identical extraction. Full-resolution working artwork is retained in the task outputs. The request is limited to the icon: Telegram 12.10.6, custom functions, settings, package and signing configuration remain unchanged.
