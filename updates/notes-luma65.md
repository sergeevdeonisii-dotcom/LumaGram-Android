# Luma 12.9.0-luma.65

- Исправлено падение при отмене экспорта аккаунта в момент завершения отдельного чата. Поздние результаты безопасно отбрасываются, временный архив очищается.
- Локальные настройки, история правок, отметки удаления и закрепы подарков изолированы по Telegram user ID. Выход очищает личные локальные данные; замена аккаунта в том же слоте больше не переносит их другому пользователю.
- Локальный уровень создаётся и у аккаунта без серверного рейтинга. Прогресс сохраняется, серверный объект не меняется.
- Сворачивание приложения и закрытие/смена чата не отправляют текст раньше выбранной локальной задержки. Таймер хранит исходный аккаунт и диалог; текст не отправляется из заменившего аккаунта.
- После установки обновления удаляются собственные старые APK, включая ранее потерянные файлы. Остальные файлы и более новые APK не затрагиваются.
- Смена источника обновлений инвалидирует старую проверку и запускает новую. Опоздавший ответ старого источника не меняет новую версию.
- После частичной ошибки «Скрыть/Открыть все подарки» список обновляется, отражая уже выполненные изменения.

## Миграция локальных данных

Переключатели призрака, серверной отправки через 20 секунд и сохранения удалённых сообщений переносятся один раз. Старые записи истории правок и отметки удаления без достоверного владельца автоматически не импортируются. Реальные сообщения не удаляются.

Локальные номер, уровень, визуальную галочку, экономный режим и закрепы подарков потребуется настроить заново. Реальные номер, рейтинг, подарки и серверные закрепы Telegram не меняются. Последующие настройки сохраняются в отдельном хранилище своего аккаунта.

Локальная короткая задержка с отменой — таймер работающего процесса, не долговечная очередь после принудительного завершения приложения. Серверная 20-секундная отправка призрака работает отдельно.

Это обновление не изменяет restrictions API key в Firebase/Google Cloud и не подтверждает устранение Firebase 403 или доставку push на конкретном телефоне.
